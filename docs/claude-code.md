# Claude Code로 Otto 프로그램하기

말로 설명하면 **AI(Claude)가 프로그램을 만들고, 컴파일하고, 로봇에 올리기까지** 해 주는 방법입니다.
나는 "어떻게 움직이게 하고 싶은지" 말하고, 로봇이 어떻게 움직였는지 알려 주기만 하면 됩니다.

```
나: "손을 가까이 대면 뒤로 물러나고 LED를 빨간색으로 켜 줘"
        ↓
Claude: 프로그램 작성 → 컴파일 → 오류 수정 → 로봇에 업로드 → 시리얼 출력 확인
        ↓
나: "뒤로 가긴 하는데 너무 느려"
        ↓
Claude: 속도를 고쳐서 다시 업로드
```

> 채팅(claude.ai)에서 코드를 받아 Arduino IDE에 붙여 넣는 더 간단한 방법은 [README의 방법 A](../README.md#방법-a-claudeai-채팅으로-하기-가장-쉬움)를 보세요.

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| Otto 로봇 | 조립하고 **[로봇 맞추기]까지 저장한 상태** (2장) |
| 배터리 | 서보는 배터리로 구동하세요. USB만 쓰면 걷다가 재부팅됩니다 |
| USB-C 케이블 | **데이터 전송이 되는** 케이블 (충전 전용 케이블은 안 됨) |
| 컴퓨터 | Windows 10/11 (macOS도 가능) |
| Claude 요금제 | Claude Code는 **Pro 이상의 유료 요금제**가 필요합니다 |

## 2. 먼저 할 일: 로봇 맞추기 저장

내 프로그램을 올리면 공식 펌웨어(웹 조종, AI 대화, 로봇 맞추기)가 덮어써집니다.
그래서 **먼저 공식 펌웨어에서 [로봇 맞추기]를 하고 [저장]** 해 둡니다. ([제작 가이드 3.1](guide.md#-31-로봇-맞추기-웹에서-하기))

저장한 보정값은 보드 안에 남아 있어서, 내 프로그램의 `ottoInit()`이 그 값을 그대로 불러 씁니다.

## 3. 프로그램 설치 (처음 한 번, 3개만)

내가 직접 설치하는 것은 아래 3개뿐입니다. 나머지(저장소, 컴파일 도구, 보드 패키지, 라이브러리)는 4장에서 **Claude가 설치합니다.**

| 순서 | 프로그램 | 받는 곳 | 설명 |
|---|---|---|---|
| 1 | **Git** | https://git-scm.com/download/win | Claude Code가 Windows에서 명령을 실행할 때 필요합니다. 설치 옵션은 모두 기본값으로 |
| 2 | **VS Code** | https://code.visualstudio.com | Claude와 대화하고 파일을 보는 편집기 |
| 3 | **Claude Code 확장** | VS Code 왼쪽 **확장(Extensions)** 아이콘 → `Claude Code` 검색 → 설치 | 설치 후 Claude 계정으로 로그인 |

> Arduino IDE는 없어도 됩니다. 이미 설치되어 있으면 Claude가 그 안의 컴파일 도구를 그대로 씁니다.

## 4. Claude에게 개발 환경 만들기 맡기기

1. 내 컴퓨터에 **빈 폴더**를 하나 만듭니다. 예: `문서\otto`
2. VS Code에서 **파일 → 폴더 열기**로 그 빈 폴더를 엽니다. ("이 폴더의 작성자를 신뢰합니까?"가 나오면 **예**)
3. 오른쪽 위의 **Claude 아이콘**(✱)을 눌러 Claude Code 창을 엽니다.
4. 아래 문장을 그대로 붙여 넣습니다.

```
https://github.com/kdi6033/otto 저장소를 이 폴더에 내려받고,
그 안의 CLAUDE.md를 읽은 다음 Otto 개발 환경을 만들어 줘.
```

Claude가 아래 일을 차례로 하면서 한 줄씩 알려 줍니다.

| Claude가 하는 일 | 걸리는 시간 |
|---|---|
| 저장소 내려받기 (`git clone`) | 1분 이내 |
| 컴파일 도구(arduino-cli) 설치 | 1~2분 |
| ESP32 보드 패키지 설치 | **5~15분** (내려받는 양이 많습니다) |
| 라이브러리 설치 (OttoI2R, FastLED, U8g2 등) | 1~2분 |
| 시험 컴파일 (hello_otto) | 1~3분 |

- 명령을 실행할 때마다 **허용할지 묻는 창**이 뜹니다. 내용을 보고 **허용(Yes)** 을 누르세요.
- Windows가 "이 앱이 디바이스를 변경하도록 허용하시겠어요?"라고 물으면 **예**를 누르세요. (컴파일 도구 설치)
- 마지막에 **"✅ 개발 환경 준비 완료"** 가 나오면 끝입니다.

> 다음부터는 VS Code에서 이 폴더를 열고 Claude 창을 열기만 하면 됩니다. Claude가 `CLAUDE.md`를 자동으로 읽습니다.

## 5. 첫 프로그램 올리기

로봇을 USB로 연결하고 배터리를 켠 뒤 입력합니다.

```
my_sketches/hello_otto 를 로봇에 올려 줘.
```

Claude가 포트를 찾고, 업로드하고, 시리얼 출력을 확인합니다. 로봇이 엉덩이를 흔들어 인사하고 세 걸음 걸으면 성공입니다.
버튼을 누를 필요는 없습니다. USB만 연결되어 있으면 자동으로 업로드됩니다.

## 6. 내 프로그램 만들기

하고 싶은 것을 **평소 말투로** 설명하세요. 쉬운 것부터 해 보세요.

| 단계 | 이렇게 말해 보세요 |
|---|---|
| 1. 동작 | "앞으로 5걸음 걷고, 뒤로 5걸음 걷고, 멈춰 줘" |
| 2. 반복과 속도 | "처음엔 천천히 걷다가 점점 빨라지게 해 줘" |
| 3. LED | "걸을 때는 LED를 초록색, 멈추면 빨간색으로 해 줘" |
| 4. OLED | "OLED에 눈을 그리고, 걸을 때 눈동자가 움직이게 해 줘" |
| 5. 센서 | "거리 센서로 15cm 안에 물건이 있으면 뒤로 물러났다가 왼쪽으로 돌아서 다시 걸어 줘" |
| 6. 여러 기능 | "장애물을 피해 다니는 순찰 로봇을 만들어 줘. 장애물을 만나면 OLED 눈이 놀란 표정이 돼" |
| 7. Wi-Fi | "휴대폰 웹 화면에서 앞, 뒤, 좌, 우 버튼으로 조종하게 해 줘" |

**잘 되는 대화 요령**

- 로봇이 **실제로 어떻게 움직였는지** 구체적으로 말합니다. Claude는 로봇을 볼 수 없습니다.
  - 좋음: "앞으로 3걸음 가다가 오른쪽으로 휘고, 4번째 걸음에서 멈췄어"
  - 아쉬움: "이상해"
- 한 번에 하나씩 고칩니다. 잘 되면 다음 기능을 덧붙입니다.
- 걷다가 멈추고 다시 시작하면 **배터리**부터 확인합니다.
- 잘 된 프로그램은 이름을 붙여 둡니다. "이 프로그램을 patrol_v1 로 저장해 줘"
- 모르는 부분은 물어봅니다. "walkFront(100)에서 100은 무슨 뜻이야?"

## 7. 공식 펌웨어로 돌아가기

웹 조종이나 AI 대화를 다시 쓰려면 i2r.link에서 펌웨어를 다시 설치합니다.
이때 보정값이 지워지므로 [로봇 맞추기]를 다시 하고 저장하세요.

## 8. 저장소 업데이트

새 예제나 문서가 올라오면 Claude에게 말합니다.

```
저장소를 최신으로 업데이트해 줘.
```

`my_sketches` 안의 내 프로그램은 그대로 남습니다.
