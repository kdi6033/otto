## ✅ 1. 서보모터 이름, 역할, 연결 핀

Otto I2R는 서보모터 4개로 걷습니다. 이름은 **[관절 종류][좌/우]** 2글자 규칙으로 짓습니다. 이렇게 하면 이름만 보고도 "어떤 동작을 하는 서보인지"와 "왼쪽인지 오른쪽인지"를 바로 알 수 있습니다.

보드의 4, 5, 6, 7번 핀을 사용하며, `Otto.init()` 함수의 인자 순서(`YL, YR, RL, RR`)와 동일하게 번호를 맞춰서 헷갈리지 않도록 합니다.

| 이름 | 뜻 | 위치 | 연결 핀 | 서보 종류 | 하는 일 |
|---|---|---|---|---|---|
| **YL** | Yaw Left | 왼쪽 엉덩이 | 4 | 180도 각도조절 | 다리를 좌우로 기울여 무게중심을 이동시킴 (반대쪽 발을 바닥에서 뜨게 함) |
| **YR** | Yaw Right | 오른쪽 엉덩이 | 5 | 180도 각도조절 | 다리를 좌우로 기울여 무게중심을 이동시킴 (반대쪽 발을 바닥에서 뜨게 함) |
| **RL** | Roll Left | 왼쪽 발 | 6 | 360도 연속회전 | 발을 굴려서 실제로 앞으로 내딛음 (걸음을 만드는 동작) |
| **RR** | Roll Right | 오른쪽 발 | 7 | 360도 연속회전 | 발을 굴려서 실제로 앞으로 내딛음 (걸음을 만드는 동작) |

<img src="../images/otto-servos-guide.png" alt="Otto 서보모터 이름 (RR, YR, YL, RL)" width="304">

> 이 이름은 Otto DIY 공식 아두이노 라이브러리(`Otto.h`)의 명명 규칙과 동일합니다. 같은 이름을 쓰면 공식 예제 코드와 튜토리얼을 그대로 참고할 수 있어 편리합니다.

> ⚠️ **좌/우 기준**: 사람이 로봇을 마주 보는 방향이 아니라, **로봇이 스스로 앞을 바라보는 방향**을 기준으로 왼쪽/오른쪽을 정합니다. 즉 로봇과 마주 서면 사람 눈에는 좌우가 반대로 보입니다.

### ✅ 1.1 회로도 (배선도)

i2r-05 보드의 커넥터와 연결 핀을 한눈에 정리한 그림입니다. 서보 커넥터는 보드에 인쇄된 이름(RR, RL, YR, YL)과 같은 자리에 꽂으면 됩니다.

<img src="../images/otto-wiring.png" alt="Otto I2R 배선도: 서보, LED 링, 스피커, 마이크, I2C, 시리얼 연결 핀" width="900">

- 서보는 **GP04(YL), GP05(YR), GP06(RL), GP07(RR)** 입니다. 각 커넥터는 신호 / 5V / GND 3핀입니다.
- LED 링 데이터는 **GP01**, 스피커 앰프는 **GP11~GP14**, 마이크는 **GP08~GP10**, I2C(OLED, 거리 센서)는 **SDA GP18 · SCL GP17** 입니다.
- 서보와 LED는 전류를 많이 쓰므로 USB만 쓰지 말고 외부 전원(배터리)을 연결하세요.

**전체 회로도** (KiCad 설계 도면)

<img src="../images/otto-schematic.png" alt="i2r-05 쉴드 회로도 (KiCad)" width="900">

> 회로도의 서보 커넥터 위에 적힌 글자(RL, RF, LL, LF)는 예전 이름입니다. 실제 연결은 위 배선도와 같이 **J8 = YL, J7 = YR, J6 = RL, J5 = RR** 입니다.

### ✅ 1.2 Otto I2R Robot 아두이노 라이브러리 설치

Otto를 Arduino IDE로 프로그래밍하려면 **OttoI2R 라이브러리**를 설치합니다. 라이브러리 관리자에서 설치하는 방법이 가장 쉽습니다.

**방법 1. Arduino IDE 라이브러리 관리자 (권장)**

1. Arduino IDE 왼쪽의 **라이브러리 관리자**(책 모양 아이콘)를 엽니다. (또는 **스케치 → 라이브러리 포함하기 → 라이브러리 관리**)
2. 검색창에 `OttoI2R`을 입력합니다.
3. **OttoI2R by i2r**의 **INSTALL**을 누릅니다. 설치되면 `1.0.0 installed`로 바뀝니다.

<img src="../images/otto-arduino-lib.png" alt="Arduino IDE 라이브러리 관리자에서 OttoI2R 설치" width="300">

**방법 2. ZIP 파일로 설치** (라이브러리 관리자에서 찾을 수 없을 때)

1. [OttoI2R 저장소](https://github.com/kdi6033/OttoI2R) 위쪽의 초록색 **Code** 버튼 → **Download ZIP**을 눌러 ZIP 파일을 내려받습니다. (GitHub에 로그인하지 않아도 됩니다)
2. Arduino IDE에서 **스케치 → 라이브러리 포함하기 → .ZIP 라이브러리 추가**를 누르고 내려받은 ZIP 파일을 선택합니다. ZIP 파일의 압축은 풀지 않습니다.

설치 후에는 어느 방법이든 **파일 → 예제 → OttoI2R**에서 예제를 열 수 있습니다.

- **추가로 설치할 라이브러리는 없습니다.** 서보는 ESP32 기본 PWM(LEDC)으로 직접 구동합니다.
- **ESP32 보드 패키지 3.0 이상**이 필요합니다. (보드 매니저에서 `esp32 by Espressif Systems` 3.x 설치)

라이브러리의 사용법과 함수 목록은 [OttoI2R 저장소 README](https://github.com/kdi6033/OttoI2R)를 참조하세요.

## ✅ 2. 프로젝트 구조

이 프로젝트는 세 부분으로 나뉩니다.

| 위치 | 내용 | 누가 다루는가 |
|---|---|---|
| **GitHub 저장소** | 동작 프로그램 여러 개(약 50개) | 사용자가 주소만 알려 줌 |
| **OttoI2R 라이브러리** | 걷기, 회전, 정지 등 실제 동작 코드 | 정교한 조작이 필요할 때 변수를 수정 |
| **웹 [로봇 맞추기]** | 로봇마다 다른 보정값 | 누구나 화면에서 숫자만 맞춤 |

프로그램을 만들 때는 AI에게 **저장소 주소나 참고할 유튜브 주소**를 알려 주면 됩니다. AI가 저장소의 동작 예제와 라이브러리를 보고 새 프로그램을 만들어 줍니다.

**보정값의 역할**

보정값은 **이 로봇만의 값**입니다. 같은 프로그램이라도 로봇마다 조립 상태가 달라서 값이 다르기 때문에, 프로그램 코드와 분리해 웹의 [로봇 맞추기]에서 맞추고 보드에 저장합니다.

- 프로그램 코드를 고치지 않고 숫자만 바꿔도 로봇이 보정됩니다.
- 동작 프로그램은 `ottoInit()`으로 보드에 저장된 값을 불러와 씁니다. 저장하지 않은 보드는 기본값을 씁니다.
- 로봇을 새로 조립하거나 패드를 붙이면 값을 다시 맞춥니다.



동작 프로그램을 여러 개(50개 정도) 만들어 GitHub에 올려 두고, 저장소 주소를 알려 주면 Claude가 그것을 참조해서 새 동작을 만들 수 있게 하려는 구조입니다.

## ✅ 3. 조립 후 모터 동작 확인과 초기셋

로봇의 모터마다 동작이 조금씩 다르고 바다면에서 기계적으로 미끄럼이 발생함으로 지기진시 똑바로 굴러가고 걸어가도록 보정을 해줘야 동작이 정확 합니다. 그래도 바닥의 접촉면과 마찰의 힘이 달라서 프로그램 하면서 보정해 주세요.   
1. 다리가 90도로 접히도록 보정.
2. 앞으로 직진하여 굴러가도록 RR RL 모터의 회전속도 보정.
3. 앞으로 똑바로 걸어 가도록 YR YL 의 각도로 보폭을 보정.

**보정 변수 (6개)**

위 세 가지 보정은 아래 6개의 값으로 나뉘어 보드에 저장됩니다. [3.1 로봇 맞추기](#-31-로봇-맞추기-웹에서-하기)에서 값을 바꾸고 [저장]을 누르면 보드(NVS)에 기록되고, 프로그램의 `ottoInit()`이 이 값을 불러와 씁니다.

| 순서 | 변수 | 뜻 | 범위 | 기본값 |
|---|---|---|---|---|
| 1 | `ylCenter` | 왼쪽 다리(YL)가 수직(90도)일 때의 펄스폭(us) | 1000~1900 | 1250 |
| 1 | `yrCenter` | 오른쪽 다리(YR)가 수직(90도)일 때의 펄스폭(us) | 1000~1900 | 1450 |
| 2 | `rlSpeed` | 왼발(RL) 굴림 속도(us). 두 발이 같은 속도로 똑바로 굴러가게 맞춥니다 | 0~600 | 450 |
| 2 | `rrSpeed` | 오른발(RR) 굴림 속도(us) | 0~600 | 550 |
| 3 | `tiltR` | 걷기: 오른발을 들 때 엉덩이를 기울이는 각도 | 0~45 | 20 |
| 3 | `tiltL` | 걷기: 왼발을 들 때 엉덩이를 기울이는 각도 | 0~45 | 23 |

- 순서는 위의 1, 2, 3번 보정에 해당합니다.
- 코드에서 직접 넣을 때는 `ottoSetCalibration(ylCenter, yrCenter, tiltR, tiltL, rlSpeed, rrSpeed)`로 6개를 한 번에 넣고, 일부만 바꾸려면 아래 함수를 씁니다. 인자 순서에 주의하세요.

| 함수 | 바꾸는 값 |
|---|---|
| `ottoSetHipCenter(ylCenter, yrCenter)` | 다리가 수직(90도)일 때의 위치 |
| `ottoSetSpeed(rlSpeed, rrSpeed)` | 굴릴 때의 발 속도 |
| `ottoSetTilt(tiltR, tiltL)` | 걸을 때 발을 들며 기울이는 각도 (**오른쪽이 앞**) |

- 이 함수들은 값을 바로 적용만 하고 **저장하지는 않습니다.** 보드에 저장하려면 `ottoSaveCalibration()`을 따로 부르세요. 범위를 벗어난 값은 자동으로 범위 안으로 맞춰집니다.
- 걷는 속도와 보폭 같은 고정값은 보정 변수가 아니라 라이브러리(`OttoI2R.cpp`) 안에 있습니다.

> 아직 저장하지 않은 보드는 기본값(YL 1250, YR 1450, 기울기 20/23, 속도 450/550)으로 움직입니다.
> 이 값은 한 대의 로봇에서 실측한 값이라 로봇에 따라 안 맞을 수 있으니, 먼저 [로봇 맞추기]를 하세요.
>
> 웹에서 펌웨어를 다시 설치하면 보드의 저장값이 지워집니다. 그때는 [로봇 맞추기]를 다시 하세요. ([값 복사]로 값을 적어 두면 편합니다.)

### ✅ 3.1 로봇 맞추기 (웹에서 하기)

조립이 끝난 Otto를 **웹 화면에서 맞추는** 방법입니다. 프로그램을 고치거나 다시 업로드할 필요가 없습니다. 화면에서 숫자를 바꾸면 **로봇이 바로 움직이고**, 마지막에 [저장]을 누르면 보드에 기록되어 다음 부팅부터 그 값을 씁니다.

같은 프로그램이라도 로봇마다 조립 상태가 달라서 값이 다릅니다. 그래서 처음 한 번, 그리고 다리나 패드를 다시 끼웠을 때 맞춰 주세요.

<img src="../images/otto-calibration.png" alt="OTTO 조종 - 로봇 맞추기 화면" width="560">

**시작하기**

1. 보드를 켜고 WiFi(인터넷)에 연결합니다. 서보는 **배터리(외부 전원)** 로 구동하세요. USB만 쓰면 서보가 동시에 움직일 때 보드가 재부팅될 수 있습니다.
2. 웹 [i2r.link](https://i2r.link)에 로그인하고 내 보드의 장치 화면을 엽니다.
3. **OTTO 조종**에서 운전 모드 **[로봇 맞추기]** 를 누릅니다.
4. 화면에 "보드의 현재 값을 읽는 중..."이 뜨고, 잠시 뒤 보드에 저장된 값이 나타납니다.

> 3초 안에 보드가 응답하지 않으면 오류 안내가 나옵니다. 보드가 켜져 있는지, 인터넷에 연결됐는지, 보정 기능이 들어 있는 최신 펌웨어인지 확인하세요.
> AI 대화 중에는 보정할 수 없습니다. 먼저 **AI 대화**를 끄세요.

**화면 구성**

위에서 아래로 4단계를 순서대로 진행합니다.

| 단계 | 하는 일 | 바꾸는 값 |
|---|---|---|
| 1. 조립 자세 | 다리를 0도 / 180도로 보내서 조립 | 없음 |
| 2. 다리 수직 | 두 다리를 수직(90도)으로 맞춤 | 왼쪽 다리(YL), 오른쪽 다리(YR) |
| 3. 굴리기 시험 | 두 발 속도를 맞춰서 똑바로 가게 함 | 왼발 속도(RL), 오른발 속도(RR) |
| 4. 걷기 시험 | 발을 들 때 기울기를 맞춤 | 오른발을 들 때, 왼발을 들 때 |

각 값은 **슬라이더**와 **미세 조정 버튼**(`-10 -1 +1 +10`, 걷기 기울기는 `-5 -1 +1 +5`)으로 바꿉니다. 바꾸는 즉시 보드에 전달되어 로봇이 움직입니다.

| 값 | 의미 | 범위 | 초기값(예) |
|---|---|---|---|
| 왼쪽 다리 (YL) | 왼쪽 다리가 수직(90도)이 되는 펄스폭 | 1000~1900 us | 1250 |
| 오른쪽 다리 (YR) | 오른쪽 다리가 수직(90도)이 되는 펄스폭 | 1000~1900 us | 1450 |
| 왼발 속도 (RL) | 왼발 회전 속도. 클수록 빠름 | 0~600 us | 450 |
| 오른발 속도 (RR) | 오른발 회전 속도. 클수록 빠름 | 0~600 us | 550 |
| 오른발을 들 때 | 오른발을 들 때 기울이는 각도 | 0~45 도 | 20 |
| 왼발을 들 때 | 왼발을 들 때 기울이는 각도 | 0~45 도 | 23 |

> 초기값은 한 대의 로봇에서 실측한 값입니다. 내 로봇은 값이 다르니 아래 순서대로 맞추세요.

**1단계: 조립 자세 (다리 0도 / 180도)**

1. **[모터를 0도 / 180도로 움직이기]** 를 누릅니다. 오른쪽 다리는 0도, 왼쪽 다리는 180도로 이동합니다.
2. 이 자세에서 다리를 끼우고 나사를 조입니다.

조립 중에는 이 단계만 쓰고, 조립이 끝나면 2단계로 넘어갑니다.

**2단계: 다리를 수직(90도)으로 맞추기**

다리가 몸체에 수직이어야 로봇이 바닥에 평평하게 섭니다.

1. **[모터를 90도로 움직이기]** 를 누릅니다.
2. 두 다리가 정확히 수직이 되도록 **왼쪽 다리(YL)** 와 **오른쪽 다리(YR)** 숫자를 조금씩 바꿉니다. 바꾸는 즉시 다리가 움직입니다.
3. 자와 수평계로 바닥과 수직인지 확인합니다. 로봇마다 두 다리 값이 같지 않아도 됩니다.

**3단계: 굴리기 시험 (두 발 속도)**

두 발을 같은 속도로 굴렸을 때 로봇이 똑바로 가야 합니다.

1. 로봇을 **바닥의 직선 자리**(예: 탁자 위 긴 줄을 따라)에 놓습니다.
2. **[앞으로 굴리기]** 를 누릅니다. **[정지]** 를 누를 때까지 계속 굴러갑니다.
3. 로봇이 한쪽으로 휘면 느린 쪽 발의 속도를 키웁니다.
   - 로봇이 **왼쪽**으로 휘면 왼발이 느린 것이므로 **왼발 속도(RL)** 를 키웁니다.
   - 로봇이 **오른쪽**으로 휘면 오른발이 느린 것이므로 **오른발 속도(RR)** 를 키웁니다.
4. 한 번에 **±10 이내**로만 바꾸고, 직진할 때까지 반복합니다. 약 1m를 두 번 이상 확인하세요.
5. 끝나면 **[정지]** 를 누릅니다.

**4단계: 걷기 시험 (발을 들 때 기울기)**

걸을 때 발이 바닥에서 수평으로 들리도록 기울기를 맞춥니다. **먼저 2단계에서 다리 수직을 맞춰 두세요.**

1. 로봇을 **평평한 바닥**(실제로 걸을 바닥)에 놓습니다.
2. **[걷기 시작]** 을 누릅니다. **[정지]** 를 누를 때까지 앞으로 걷습니다.
3. 걷는 모습을 보고 아래 기준으로 조정합니다.

| 관찰 | 조정 |
|---|---|
| 발이 바닥에서 들리지 않음 | 해당 발의 기울기를 키움 |
| 발이 너무 높이 들려 몸이 흔들림 | 해당 발의 기울기를 줄임 |
| 한쪽으로 자꾸 돎 | 돌아가는 쪽 발의 기울기를 키움 |
| 한쪽 발만 걸음이 짧음 | 그 발의 기울기를 키움 |

4. 한 번에 **±1~5도**씩만 바꾸고, 10걸음 이상 걸어 확인합니다.
5. 개선이 없으면 원래 값으로 되돌립니다.

**저장하기**

값을 바꾸면 화면에 "⚠ 아직 저장하지 않은 값입니다"가 표시됩니다. 다 맞추면 아래 버튼을 누릅니다.

| 버튼 | 하는 일 |
|---|---|
| **저장 (보드 NVS)** | 맞춘 값을 보드에 기록합니다. 다음 부팅부터 이 값을 씁니다. 저장되면 "✅ 보드에 저장된 값이 있습니다"가 표시됩니다. |
| **값 복사** | 현재 값을 문자열로 복사합니다. 예: `YL=1250, YR=1450, 오른발기울기=20, ...` |
| **기본값으로** | 저장된 값을 지우고 기본값으로 되돌립니다. (확인 창이 뜹니다) |

> **웹에서 펌웨어를 다시 설치하면 보드의 저장값이 지워집니다.** 저장 전후에 **[값 복사]** 로 값을 따로 기록해 두세요.
> **[닫기]** 를 누르거나 다른 화면으로 가면 시험 동작은 자동으로 멈춥니다.

**주의 사항**

- **패드를 붙이거나 떼면 다시 맞추세요.** 발 높이가 바뀌면 기울기 값도 달라집니다.
- 배터리 전압이 낮으면 걸음이 약해져 기울기를 잘못 맞출 수 있습니다. 같은 배터리로 하세요.
- 바닥 재질에 따라 미끄럼이 달라서 걸음 모양이 바뀝니다. 실제로 걸을 바닥에서 맞추세요.

**동작 원리 (참고)**

- 화면에서 값을 바꾸면 MQTT로 보드에 전달됩니다. (명령 `ottoCal`, 값 변경은 0.15초에 한 번 전송)
- 보드는 값을 바로 적용하고, [저장]을 누르면 보드의 NVS 메모리에 기록합니다.
- 보드는 부팅할 때 저장된 값을 읽어 씁니다. (OttoI2R 라이브러리의 `ottoLoadCalibration`)

### ✅ 3.2 앞으로 걷기 (walk_front)

Otto I2R 로봇이 **앞으로 똑바로 걷게** 하는 프로그램입니다. 오른발과 왼발을 번갈아 한 걸음씩 내딛습니다. 걸음 동작은 `OttoI2R` 라이브러리의 `walkFront()` 함수 하나에 들어 있으니, 프로그램에는 함수 호출만 적습니다.

**걸음 순서**
1. 오른쪽으로 기울여 오른발을 들어 올립니다.
2. 오른발을 굴려 앞으로 내딛습니다.
3. 다리를 가운데(90도)로 되돌리고 잠시 멈춥니다.
4. 왼쪽으로 기울여 왼발을 들어 올립니다.
5. 왼발을 굴려 앞으로 내딛습니다.
6. 다리를 가운데로 되돌리고 잠시 멈춥니다. 1번으로 돌아가 반복합니다.

**걷는 속도 바꾸기 (walkFront(VELOCITY))**

지금까지는 `walkFront();`라고 쓰면 로봇이 **보통 속도**로 걸었습니다. 이 보통 속도가 숫자 **100**입니다.

괄호 안에 숫자를 넣으면 걷는 속도를 바꿀 수 있습니다. 숫자는 **40부터 200까지** 쓸 수 있습니다.

```c
walkFront();      // 보통 속도 (walkFront(100) 과 같아요)
walkFront(60);    // 천천히 걷기
walkFront(150);   // 빠르게 걷기
```

| 쓰는 숫자 | 로봇이 걷는 모습 |
|---|---|
| 40 | 아주 천천히 걸어요 🐢 |
| 60 ~ 80 | 천천히 걸어요 |
| **100** | **보통 속도예요 (기본)** |
| 120 ~ 150 | 빠르게 걸어요 |
| 200 | 가장 빠르게 걸어요 🐇 |

- **숫자가 클수록 빨리 걷습니다.** 100이 기준이에요. 100보다 작으면 느리고, 100보다 크면 빨라요.
- `walkFront(숫자);`는 한 걸음(오른발, 왼발)을 걷고 끝나요. 계속 걷게 하려면 `loop()` 안에 넣어 두면 됩니다.
- 숫자를 이름이 있는 상자(`VELOCITY`)에 넣어 두면 숫자 하나만 바꿔서 쉽게 실험할 수 있어요.

```c
const int VELOCITY = 150;   // 걷는 속도 (40~200 사이 숫자)

void loop() {
  walkFront(VELOCITY);
}
```

> 💡 **실험해 보세요!** `VELOCITY`를 40, 100, 200으로 바꿔서 올려 보고 로봇이 어떻게 달라지는지 관찰해 보세요.
> ⚠️ 너무 빠르면 발이 잘 안 들리거나 한쪽으로 휠 수 있어요. 그럴 때는 숫자를 조금 줄여 보세요. 건전지가 약해도 잘 못 걸어요.

**속도를 바꿔 가며 걷기 (walk_front_speed)**

로봇이 **느리게 걷기 시작해서 점점 빨라지고, 다시 점점 느려지는** 예제예요.

- `speed`는 속도 숫자를 담는 상자예요. 40에서 시작해서 20씩 커져서 200까지 가요.
- `for`는 같은 일을 여러 번 되풀이하게 해 줘요. 첫 번째 `for`는 속도를 **올리고**, 두 번째 `for`는 속도를 **내려요**.
- `walkFront(speed);`를 두 번 써서 속도마다 **두 걸음**씩 걸어요.
- 시리얼 모니터(115200)를 열면 지금 속도 숫자가 나와요.

로봇이 걷는 속도는 이렇게 바뀌어요.

> 40 → 60 → 80 → 100 → 120 → ... → 200 → 180 → ... → 60 → 40 → (다시 처음부터)

<br>
<details>
    <summary>💻 속도를 바꿔 가며 걷기 (walk_front_speed.ino) </summary>

```c
#include <OttoI2R.h>

// 속도를 바꿔 가며 걷기 (쉬운 버전)
// walkFront(숫자)는 그 숫자의 속도로 걸어요. 100이 보통 속도, 클수록 빨라요. (40 ~ 200)
// 느린 속도에서 빠른 속도까지 올라갔다가, 다시 느린 속도까지 내려와요.

void setup() {
  ottoInit();   // 로봇을 준비해요
}

void loop() {
  // 40, 60, 80 ... 200 : 점점 빨라져요
  for (int speed = 40; speed <= 200; speed = speed + 20) {
    Serial.println(speed);   // 지금 속도를 보여 줘요
    walkFront(speed);        // 한 걸음 (오른발, 왼발)
    walkFront(speed);        // 한 걸음 더
  }

  // 200, 180, 160 ... 40 : 점점 느려져요
  for (int speed = 200; speed >= 40; speed = speed - 20) {
    Serial.println(speed);
    walkFront(speed);
    walkFront(speed);
  }
}
```
</details>

### ✅ 3.3 뒤로 걷기 (walk_back)

Otto I2R 로봇이 **뒤로 똑바로 걷게** 하는 프로그램입니다. 오른발과 왼발을 번갈아 한 걸음씩 내딛습니다. 걸음 동작은 `OttoI2R` 라이브러리의 `walkBack()` 함수 하나에 들어 있으니, 프로그램에는 함수 호출만 적습니다.

**걸음 순서**

뒤로 걸을 때는 **바닥에 디딘 발**을 뒤쪽으로 굴립니다. 들린 발을 굴리면 몸이 앞으로 가므로 쓰지 않습니다.

1. 오른쪽으로 기울여 한쪽 발을 들어 올립니다.
2. 바닥에 디딘 오른발(RR)을 뒤로 굴립니다.
3. 다리를 가운데(90도)로 되돌리고 잠시 멈춥니다.
4. 왼쪽으로 기울여 반대쪽 발을 들어 올립니다.
5. 바닥에 디딘 왼발(RL)을 뒤로 굴립니다.
6. 다리를 가운데로 되돌리고 잠시 멈춥니다. 1번으로 돌아가 반복합니다.

> `walk_front`와 비교하면 굴리는 발과 방향이 반대입니다. `walk_front`는 앞으로 가는 방향으로, `walk_back`은 같은 발을 반대 방향으로 굴립니다.

**걷는 속도 바꾸기 (walkBack(VELOCITY))**

`walkBack();`이라고 쓰면 로봇이 **보통 속도**로 뒤로 걸어요. 이 보통 속도가 숫자 **100**이에요.

괄호 안에 숫자를 넣으면 뒤로 걷는 속도를 바꿀 수 있어요. 숫자는 **40부터 200까지** 쓸 수 있어요.

```c
walkBack();      // 보통 속도 (walkBack(100) 과 같아요)
walkBack(60);    // 천천히 뒤로 걷기
walkBack(150);   // 빠르게 뒤로 걷기
```

- **숫자가 클수록 빨리 걸어요.** 100이 기준이에요. (앞으로 걷기 `walkFront(숫자)`와 똑같아요.)
- `walkBack(숫자);`는 한 걸음(오른발, 왼발)을 걷고 끝나요. 계속 걷게 하려면 `loop()` 안에 넣어 두면 됩니다.

> ⚠️ 너무 빠르면 발이 잘 안 들리거나 한쪽으로 휠 수 있어요. 그럴 때는 숫자를 조금 줄여 보세요. 건전지가 약해도 잘 못 걸어요.

<br>     
<details>

**속도를 바꿔 가며 뒤로 걷기 (walk_back_speed)**

로봇이 **느리게 뒤로 걷기 시작해서 점점 빨라지고, 다시 점점 느려지는** 예제예요.

- `speed`는 속도 숫자를 담는 상자예요. 40에서 시작해서 20씩 커져서 200까지 가요.
- `for`는 같은 일을 여러 번 되풀이하게 해 줘요. 첫 번째 `for`는 속도를 **올리고**, 두 번째 `for`는 속도를 **내려요**.
- `walkBack(speed);`를 두 번 써서 속도마다 **두 걸음**씩 걸어요.
- 시리얼 모니터(115200)를 열면 지금 속도 숫자가 나와요.

> 40 → 60 → 80 → 100 → 120 → ... → 200 → 180 → ... → 60 → 40 → (다시 처음부터)

<br>
<details>
    <summary>💻 속도를 바꿔 가며 뒤로 걷기 (walk_back_speed.ino) </summary>

```c

// 속도를 바꿔 가며 뒤로 걷기 (쉬운 버전)
// walkBack(숫자)는 그 숫자의 속도로 뒤로 걸어요. 100이 보통 속도, 클수록 빨라요. (40 ~ 200)
// 느린 속도에서 빠른 속도까지 올라갔다가, 다시 느린 속도까지 내려와요.

void setup() {
  ottoInit();   // 로봇을 준비해요
}

void loop() {
  // 40, 60, 80 ... 200 : 점점 빨라져요
  for (int speed = 40; speed <= 200; speed = speed + 20) {
    Serial.println(speed);   // 지금 속도를 보여 줘요
    walkBack(speed);         // 한 걸음 (오른발, 왼발)
    walkBack(speed);         // 한 걸음 더
  }

  // 200, 180, 160 ... 40 : 점점 느려져요
  for (int speed = 200; speed >= 40; speed = speed - 20) {
    Serial.println(speed);
    walkBack(speed);
    walkBack(speed);
  }
}
```

### ✅ 3.10 앞으로 굴리기 (rolling_front)

Otto I2R 로봇의 **두 발을 멈추지 않고 계속 앞으로 굴리는** 프로그램입니다. 엉덩이는 처음 한 번만 끝까지 돌려 두고, 그 뒤에는 발이 계속 굴러갑니다. 동작은 `OttoI2R` 라이브러리의 `rollingFront()` 함수 하나에 들어 있으니, 프로그램에는 함수 호출만 적습니다.    

**동작 순서**    

1. 처음 한 번만 `YR`을 0도, `YL`을 180도로 움직이고 1초 머무릅니다.
2. 왼발(RL)은 앞으로(`+`), 오른발(RR)은 앞으로(`-`) **멈추지 않고 계속** 굴립니다.
3. 호출이 반복되어도 정지 명령을 주지 않으므로 회전이 이어집니다.

> 멈추려면 보드를 리셋하거나 전원을 끄세요. 이 함수에는 정지 기능이 없습니다.

**굴러가는 속도 바꾸기 (rollingFront(VELOCITY))**

`rollingFront();`라고 쓰면 로봇이 **보통 속도**로 굴러가요. 이 보통 속도가 숫자 **100**이에요.

괄호 안에 숫자를 넣으면 굴러가는 속도를 바꿀 수 있어요. 숫자는 **40부터 200까지** 쓸 수 있어요.

```c

rollingFront(60);    // 천천히 굴러가요
```

### ✅ 3.11 뒤로 굴리기 (rolling_back)

### ✅ 3.14 엉덩이 각도 직접 입력하기 (hip_move)

Otto I2R 로봇의 **두 엉덩이(오른쪽 `YR`, 왼쪽 `YL`)를 각도로 움직이는** 프로그램입니다. 시리얼 모니터에 숫자 두 개를 입력하면 그 각도로 엉덩이가 움직입니다. 발(RL, RR)은 움직이지 않습니다. 움직이는 동작은 `OttoI2R` 라이브러리의 `moveHip(yr, yl)` 함수 하나에 들어 있으니, 프로그램에는 함수 호출만 적습니다.

**사용 방법**

1. 시리얼 모니터를 **115200**으로 엽니다.
2. 숫자 두 개를 **띄어서** 입력하고 Enter를 누릅니다.

| 입력 | 결과 |
|---|---|
| `80 100` | 오른쪽 엉덩이(YR) 80도, 왼쪽 엉덩이(YL) 100도 |
| `90 90` | 두 엉덩이 모두 가운데(90도) |
| `70 110` | 오른쪽 엉덩이 70도, 왼쪽 엉덩이 110도 |

> 첫 번째 숫자는 **오른쪽**(`YR`), 두 번째 숫자는 **왼쪽**(`YL`)입니다.
> 각도는 **0 ~ 180** 사이이고, **90이 가운데**입니다. 범위를 벗어나면 0 또는 180으로 제한됩니다.

**각도 기준 (반드시 읽어 주세요)**

- **0 ~ 180 사이의 숫자를 입력합니다.** 이 범위 밖의 숫자는 자동으로 0 또는 180으로 바뀝니다.
- **90도가 가운데(중립)입니다.** 엉덩이는 처음에 90도에 있고, 입력하지 않으면 움직이지 않습니다.

| 각도 | 엉덩이 모양 |
|---|---|
| **0** | 한쪽 끝까지 기운 자세 |
| **90** | **가운데 (중립)**, 몸과 수직 |
| **180** | 반대쪽 끝까지 기운 자세 |

> 90보다 작은 값은 한쪽으로, 90보다 큰 값은 반대쪽으로 기웁니다. 가운데에서 얼마나 떨어졌는지가 기우는 정도입니다.

**동작 순서**

1. 보드를 켜면 `setup()`이 시리얼을 열고 안내 문구를 보여 줍니다.
2. `loop()`가 시리얼 입력을 기다립니다.
3. `80 100`처럼 두 숫자를 받으면 `moveHip(80, 100)`을 호출합니다.
4. 엉덩이가 입력한 각도로 움직이고, 그 자세에 계속 머뭅니다.
5. 입력한 값을 시리얼 모니터에 보여 줍니다.

### ✅ 3.15 발을 하나씩 앞, 뒤로 굴리기 (roll_one_foot)

Otto I2R 로봇의 **오른발과 왼발을 따로따로** 앞으로, 뒤로 굴리는 예제 프로그램입니다. 한 발만 움직이고 다른 발은 멈춰 있으며, 엉덩이(YL, YR)는 움직이지 않습니다. 발을 굴리는 동작은 `OttoI2R` 라이브러리의 `rollRightFoot(속도)`와 `rollLeftFoot(속도)` 함수에 들어 있습니다.


- `rollRightFoot(속도)`: 오른발만 굴립니다.
- `rollLeftFoot(속도)`: 왼발만 굴립니다.
- `ottoInit()`: 서보를 초기화합니다. 이 프로그램은 발 속도를 숫자(80)로 직접 정하므로 보정값은 쓰지 않습니다.

**동작 순서**

1. 오른발을 앞으로 2초 굴리고, 멈춘 채 1초 기다립니다.
2. 오른발을 뒤로 2초 굴리고, 멈춘 채 1초 기다립니다.
3. 왼발을 앞으로 2초 굴리고, 멈춘 채 1초 기다립니다.
4. 왼발을 뒤로 2초 굴리고, 멈춘 채 1초 기다립니다.
5. 1번으로 돌아가 반복합니다.

**속도 규칙**

| 값 | 의미 |
|---|---|
| 양수 (예: 80) | 앞으로, 클수록 빠름 |
| 음수 (예: -80) | 뒤로, 절댓값이 클수록 빠름 |
| 0 | 멈춤 |

숫자 범위는 **-400 ~ 400**입니다. 범위 밖의 값은 자동으로 제한됩니다.

**움직임이 이상할 때**

| 증상 | 확인할 것 |
|---|---|
| 한쪽 발이 움직이지 않음 | 그 발의 서보 배선과 전원을 확인합니다. |
| 발이 계속 돌아감 | `함수(0)`을 주었는지 확인합니다. 또는 보드를 리셋합니다. |
| 앞뒤 방향이 반대임 | 함수 안의 `+`, `-` 부호가 맞는지 확인합니다. 방향 규칙은 위의 표를 따릅니다. |
| 속도가 너무 빠르거나 느림 | 숫자(80)를 줄이거나 키웁니다. |

> 두 발을 같은 방향, 같은 속도로 굴리면 로봇이 직진합니다. 한쪽으로 휘면 두 발의 숫자를 조금씩 다르게 바꿔 보세요.

<br>     
<details>
    <summary>💻 발을 하나씩 앞, 뒤로 굴리기 (roll_one_foot.ino) </summary>

```c
// 발 하나씩 움직이는 예제 (앞으로, 뒤로 모두 포함).
// 1) 오른발만 앞으로 2초 -> 멈춤 1초
// 2) 오른발만 뒤로 2초   -> 멈춤 1초
// 3) 왼발만 앞으로 2초   -> 멈춤 1초
// 4) 왼발만 뒤로 2초     -> 멈춤 1초
// 엉덩이(YL, YR)는 움직이지 않는다. 이 순서를 반복한다.
// 발 속도는 아래에서 숫자로 직접 정한다. 서보는 ottoInit()에서 초기화한다.

void setup() {
  ottoInit();
}

void loop() {

  rollRightFoot(80);      // 오른발 앞으로
  delay(2000);
  rollRightFoot(0);      // 오른발 멈춤
  delay(1000);

  rollRightFoot(-80);    // 오른발 뒤로 (역회전)
  delay(2000);
  rollRightFoot(0);      // 오른발 멈춤
  delay(1000);

  rollLeftFoot(80);      // 왼발 앞으로
  delay(2000);
  rollLeftFoot(0);       // 왼발 멈춤
  delay(1000);

  rollLeftFoot(-80);     // 왼발 뒤로 (역회전)
  delay(2000);
  rollLeftFoot(0);       // 왼발 멈춤
  delay(1000);
}

```

### ✅ 3.16 댄스 동작 만들기 (dance_right_turn, dance_left_turn)

**춤 동작: 한 발 들고 돌기 (dance)**

Otto I2R 로봇이 **한쪽 발을 들고, 반대쪽 발을 굴려서 도는** 춤 동작 모음입니다. `dance_left_turn`, `dance_right_turn` 두 프로그램이 들어 있습니다. 두 발 중 하나로만 서야 하므로, 무게중심을 맞추는 것이 가장 중요합니다.

**핵심: 무게중심 맞추기**

발을 들려면 먼저 몸무게를 **디딜 발 쪽으로 옮긴** 뒤에 들어야 넘어지지 않습니다. 이것을 `moveHip(yr, yl)`로 합니다.

```cpp
moveHip(90, 90);     // 기준 자세: 두 다리 모두 가운데(90도)
moveHip(125, 125);   // 두 다리를 더 기울여서 무게중심을 옮긴다
```

- `moveHip(yr, yl)`의 첫 번째 값은 **오른쪽 엉덩이(YR)**, 두 번째 값은 **왼쪽 엉덩이(YL)**입니다.
- 숫자가 90보다 크거나 작을수록 그만큼 기웁니다. 90이 가운데입니다.
- **값을 한 번에 정하지 말고 조금씩 바꿔 가며 시험**하세요. 로봇마다 무게 중심이 달라서, 같은 숫자를 줘도 어떤 로봇은 넘어지고 어떤 로봇은 멀쩡합니다.
- 예를 들어 `moveHip(55, 55)`처럼 더 작은 값으로 반대쪽으로 기울여 보는 것도 균형을 맞추는 한 방법입니다. 몸이 앞뒤, 좌우 어느 쪽으로도 기울지 않는 값을 찾는 것이 목표입니다.
- 각도를 찾을 때는 **로봇을 손으로 받칠 수 있는 상태**에서 조금씩 올려 보고, 넘어지지 않는 범위를 확인한 뒤 프로그램에 넣으세요.

**dance_left_turn**

왼쪽 한발로 지탱하고 회전 합니다.


<br>     
<details>
    <summary>💻 왼쪽 한발로 지탱하고 회전 (dance_left_turn.ino) </summary>

```c
#include <OttoI2R.h>

void setup() {
  ottoInit();
}

void loop() {
  moveHip(90, 90);
  delay(2000);
  moveHip(125, 125);
  delay(2000);

  rollLeftFoot(150);     // 땅에 디딘 왼발을 굴려 왼쪽으로 돈다
  delay(2000);
  rollLeftFoot(0);      // 왼발 멈춤
  delay(2000);
  rollLeftFoot(-150);     // 땅에 디딘 왼발을 굴려 왼쪽으로 돈다
  delay(2000);
  rollLeftFoot(0);      // 왼발 멈춤
}
```
</details>

**동작 순서**
1. 두 다리를 90도(기준 자세)에 둡니다.
2. 두 다리를 125도로 기울여 무게중심을 옮기고, 한쪽 발을 듭니다.
3. `rollLeftFoot(150)`으로 왼발을 굴려 돕니다. 2초 뒤 멈춥니다.
4. `rollLeftFoot(-150)`으로 반대 방향으로 굴려 돕니다. 2초 뒤 멈춥니다.
5. 1번으로 돌아가 반복합니다.

**dance_right_turn**

오른쪽 한발로 지탱하고 회전 합니다. 이 프로그램은 두 다리를 **55도**로 기울여 무게중심을 옮깁니다. (dance_left_turn은 125도)

```c
#include <Wire.h>
#include <U8g2lib.h>
#include <math.h>

U8G2_SH1106_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, /* reset=*/ U8X8_PIN_NONE);

void setup() {
  Wire.begin(18, 17);      // 사용자 정의 I2C 핀: SDA=18, SCL=17
  u8g2.begin();
}

void loop() {
  u8g2.clearBuffer();

  drawSleepingEye(40, 32);  // 왼쪽 눈
  drawSleepingEye(88, 32);  // 오른쪽 눈

  u8g2.sendBuffer();
  delay(1000);
}

void drawSleepingEye(int cx, int cy) {
  const int radius = 16;
  const int eyelash_len = 5;
  const int start_deg = 30;
  const int end_deg = 150;

  // 눈꺼풀: 아래로 휘어진 부드러운 원호
  for (int angle = start_deg; angle <= end_deg; angle++) {
    float rad = angle * PI / 180.0;
    int x = cx + radius * cos(rad);
    int y = cy + radius * sin(rad);
    u8g2.drawPixel(x, y);
  }

  // 속눈썹: 원호 위에 일정 각도 간격으로, 접선의 수직 방향(법선 방향)으로 짧게 그리기
  for (int angle = start_deg; angle <= end_deg; angle += 10) {
    float rad = angle * PI / 180.0;

    int x1 = cx + radius * cos(rad);
    int y1 = cy + radius * sin(rad);

    // 접선의 수직 방향 = 원호의 법선 방향 (아래 방향)
    float dx = cos(rad + PI / 2.0);
    float dy = sin(rad + PI / 2.0);

    int x2 = x1 + eyelash_len * dx;
    int y2 = y1 + eyelash_len * dy;

    u8g2.drawLine(x1, y1, x2, y2);
  }
}
```

    <summary>💻  무지개 🌈 / 점멸 ✨ / 흐름 💨 </summary>

```c
#include <FastLED.h>

#define NUM_LEDS 16       // LED 개수
#define DATA_PIN 9        // 데이터 핀 (D9)
#define LED_TYPE WS2812B  // LED 종류
#define COLOR_ORDER GRB   // 색 순서

CRGB leds[NUM_LEDS];
uint8_t gHue = 0;         // 무지개 색상 변화용

void setup() {
  FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);
  FastLED.clear();
  FastLED.show();
}

void loop() {
  rainbowEffect();      // 무지개 효과
  blinkEffect();        // 점멸 효과
  flowingEffect();      // 흐름 효과
}

// 🌈 무지개 효과
void rainbowEffect() {
  for (int i = 0; i < 100; i++) {
    fill_rainbow(leds, NUM_LEDS, gHue++);
    FastLED.show();
    delay(50);
  }
}

// ✨ 점멸 효과
void blinkEffect() {
  for (int i = 0; i < 5; i++) {
    fill_solid(leds, NUM_LEDS, CRGB::White); // 켜짐
    FastLED.show();
    delay(300);

    fill_solid(leds, NUM_LEDS, CRGB::Black); // 꺼짐
    FastLED.show();
    delay(300);
  }
}

// 💨 흐름 효과 (앞에서 뒤로 번지는 느낌)
void flowingEffect() {
  for (int i = 0; i < NUM_LEDS; i++) {
    leds[i] = CRGB::Blue;
    if (i > 0) leds[i - 1] = CRGB::Black; // 이전 LED 끄기
    FastLED.show();
    delay(100);
  }
  leds[NUM_LEDS - 1] = CRGB::Black; // 마지막도 끄기
  FastLED.show();
}
```
</details>


| 효과  | 설명                               |
| --- | -------------------------------- |
| 무지개 | `fill_rainbow()` 함수로 자동 색상 변화 구현 |
| 점멸  | `fill_solid()`으로 흰색-검정 반복        |
| 흐름  | 하나의 LED가 켜지면서 앞에서 뒤로 이동하는 효과     |

🛠 응용 아이디어
흐름을 양방향으로 → i = NUM_LEDS-1 ~ 0 순회    
점멸 색상 랜덤화 → CHSV(random8(),255,255)    
무지개 속도 조절 → delay(10) 또는 EVERY_N_MILLISECONDS(20)    

### ✅ 3.19 거리 센서
<img src="../images/vl53l0x-distance.png" alt="VL53L0X 거리 센서 모듈 (VIN, GND, SCL, SDA)" width="150">    

 VL53L0X Time-of-Flight (ToF) 거리센서를 사용합니다.

🔍 개요
VL53L0X는 STMicroelectronics에서 개발한 **레이저 기반 Time-of-Flight(ToF) 거리 센서**입니다.  
적외선 레이저 펄스를 발사하고 반사되는 시간을 측정하여 **매우 정확한 거리**를 측정할 수 있습니다.  
광량, 반사율, 색상에 크게 영향을 받지 않아 안정적인 측정이 가능하며, 소형 폼팩터로 IoT, 로봇, HMI 등에 적합합니다.

---

📖 주요 사양

| 항목                  | 내용                                     |
|-----------------------|------------------------------------------|
| 센서 모델             | VL53L0X                                  |
| 측정 방식             | Time-of-Flight (ToF), 적외선 레이저 사용 |
| 측정 거리             | **30mm ~ 2000mm** (일반적으로 30cm 내외가 정확) |
| 정확도                | ±3% 이내                                 |
| 분해능                | 1mm 단위                                 |
| 동작 전압             | 2.6 ~ 3.5V (보통 3.3V 또는 5V 보드 전원 지원) |
| 인터페이스            | I2C (SCL, SDA)                           |
| 동작 온도             | -20°C ~ 70°C                             |
| 레이저 클래스         | Class 1 (안전함)                         |
| I2C 주소              | 기본: 0x29                               |
| 크기                  | 약 18mm x 12mm (보드에 따라 다름)         |

---

⚙️ 핀 설명 (보드에 따라 다름)

| 핀 이름 | 기능 설명                                      |
|---------|------------------------------------------------|
| VIN     | 전원 입력 (3.3V 또는 5V)                        |
| GND     | 접지                                           |
| SDA     | I2C 데이터                                     |
| SCL     | I2C 클럭                                       |
| XSHUT   | 전원 제어 (여러 센서 사용 시 주소 설정에 활용) |
| GPIO1   | 인터럽트 출력 (일반적으로 사용하지 않음)       |

```c
#include <FastLED.h>
#include <Wire.h>
#include <U8g2lib.h>
#include <math.h>
#include "Adafruit_VL53L0X.h"

// ------------------- OLED ---------------------
U8G2_SH1106_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, /* reset=*/ U8X8_PIN_NONE);
int pupilX = 0, pupilY = 0;
int directionX = 1, directionY = 1;

// ------------------- FastLED ---------------------
#define NUM_LEDS 16
#define DATA_PIN 9
#define LED_TYPE WS2812B
#define COLOR_ORDER GRB
CRGB leds[NUM_LEDS];
uint8_t gHue = 0;
int mode = 1;  // 1:rainbow, 2:blink, 3:flow, 4:breath

// 타이머
unsigned long previousBlinkMillis = 0;
bool blinkState = false;
unsigned long previousFlowMillis = 0;
int flowIndex = 0;
unsigned long previousFrameMillis = 0;
const unsigned long frameInterval = 50;

// ------------------- Breathing ---------------------
int breathBrightness = 0;
bool breathUp = true;
unsigned long previousBreathMillis = 0;

// ------------------- VL53L0X ---------------------
Adafruit_VL53L0X lox = Adafruit_VL53L0X();
unsigned long previousDistanceMillis = 0;
const unsigned long distanceInterval = 500;

// ------------------- SETUP ---------------------
void setup() {
  Serial.begin(115200);
  delay(1000);

  Wire.begin(18, 17);  // I2C 핀 설정

  // VL53L0X 초기화
  if (!lox.begin()) {
    Serial.println(F("VL53L0X 초기화 실패!"));
    while (1);
  }

  u8g2.begin();

  FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);
  FastLED.clear();
  FastLED.show();

  Serial.println(F("시작 완료: OLED + LED + VL53L0X"));
}

// ------------------- LOOP ---------------------
void loop() {
  unsigned long currentMillis = millis();

  // 거리 측정 (0.5초 간격)
  if (currentMillis - previousDistanceMillis >= distanceInterval) {
    previousDistanceMillis = currentMillis;
    printDistance();
  }

  // 프레임 타이머
  if (currentMillis - previousFrameMillis >= frameInterval) {
    previousFrameMillis = currentMillis;

    updateEyeAnimation();

    switch (mode) {
      case 1: updateRainbowEffect(); break;
      case 2: updateBlinkEffect(); break;
      case 3: updateFlowingEffect(); break;
      case 4: updateBreathingEffect(); break;
    }
  }
}

// ------------------- VL53L0X ---------------------
void printDistance() {
  VL53L0X_RangingMeasurementData_t measure;
  lox.rangingTest(&measure, false);

  if (measure.RangeStatus != 4) {
    Serial.print("거리: ");
    Serial.print(measure.RangeMilliMeter);
    Serial.println(" mm");
  } else {
    Serial.println("측정 실패");
  }
}

// ------------------- Eye ---------------------
void updateEyeAnimation() {
  int eye1X = 32, eye2X = 96, eyeY = 32, radius = 16;

  pupilX += directionX;
  pupilY += directionY;
  if (abs(pupilX) > 5) directionX = -directionX;
  if (abs(pupilY) > 3) directionY = -directionY;

  u8g2.clearBuffer();
  u8g2.drawCircle(eye1X, eyeY, radius, U8G2_DRAW_ALL);
  u8g2.drawDisc(eye1X + pupilX, eyeY + pupilY, 5, U8G2_DRAW_ALL);
  u8g2.drawCircle(eye2X, eyeY, radius, U8G2_DRAW_ALL);
  u8g2.drawDisc(eye2X + pupilX, eyeY + pupilY, 5, U8G2_DRAW_ALL);
  u8g2.sendBuffer();
}

// ------------------- FastLED Effects ---------------------
void updateRainbowEffect() {
  fill_rainbow(leds, NUM_LEDS, gHue++);
  FastLED.show();
}

void updateBlinkEffect() {
  unsigned long currentMillis = millis();
  if (currentMillis - previousBlinkMillis >= 300) {
    previousBlinkMillis = currentMillis;
    blinkState = !blinkState;
    fill_solid(leds, NUM_LEDS, blinkState ? CRGB::White : CRGB::Black);
    FastLED.show();
  }
}

void updateFlowingEffect() {
  unsigned long currentMillis = millis();
  if (currentMillis - previousFlowMillis >= 100) {
    previousFlowMillis = currentMillis;

    fill_solid(leds, NUM_LEDS, CRGB::Black);
    leds[flowIndex] = CRGB::Blue;
    flowIndex = (flowIndex + 1) % NUM_LEDS;

    FastLED.show();
  }
}

void updateBreathingEffect() {
  unsigned long currentMillis = millis();
  if (currentMillis - previousBreathMillis >= 20) {
    previousBreathMillis = currentMillis;

    if (breathUp) {
      breathBrightness += 5;
      if (breathBrightness >= 255) {
        breathBrightness = 255;
        breathUp = false;
      }
    } else {
      breathBrightness -= 5;
      if (breathBrightness <= 0) {
        breathBrightness = 0;
        breathUp = true;
      }
    }

    fill_solid(leds, NUM_LEDS, CHSV(gHue, 255, breathBrightness));
    FastLED.show();
  }
}
```

### ✅ 3.20 조도센서 (GY302)
🔗 [📺 영상 보기 - **AI IoT 아두이노 보드 조도센서 **](https://youtu.be/GoVdq9TUvuM)

i2r‑05 보드의 I2C 핀(GPIO17=SCL, GPIO18=SDA) 에 연결된 GY‑302 (BH1750) 조도 센서용 아두이노 프로그램 입니다.
- GY-320은 GY-302의 오기일 가능성이 높으며, 실제 센서는 BH1750을 사용합니다.
- 해당 센서는 I2C 통신 방식이며, i2r‑05 보드의 핀맵에 따라 다음처럼 연결합니다:

📦 설치 라이브러리
- Arduino IDE에서 BH1750 by Christopher Laws 설치:
- Arduino IDE → 라이브러리 매니저 → BH1750 → 설치

| BH1750 (GY-302) 핀 | i2r‑05 GPIO | 설명              |
| ----------------- | ----------- | --------------- |
| VCC               | 3.3V 또는 5V  | 전원 공급           |
| GND               | GND         | 공통 접지           |
| SDA               | IO18        | I2C 데이터         |
| SCL               | IO17        | I2C 클럭          |
| ADDR              | GND (or NC) | 주소 설정 (기본 0x23) |



<br>     
<details>
    <summary>💻 조도센서 GY-302 프로그램</summary>

```c
#include <Wire.h>
#include <BH1750.h>

BH1750 lightMeter;

void setup() {
  Serial.begin(115200);

  // I2C 핀 설정 (SDA=18, SCL=17) — i2r-05 보드 전용
  Wire.begin(18, 17);

  // BH1750 초기화
  if (lightMeter.begin(BH1750::CONTINUOUS_HIGH_RES_MODE)) {
    Serial.println("✅ BH1750 시작 성공!");
  } else {
    Serial.println("❌ BH1750 초기화 실패. 연결 확인!");
    while (1);
  }
}

void loop() {
  float lux = lightMeter.readLightLevel();
  Serial.print("💡 조도: ");
  Serial.print(lux);
  Serial.println(" lux");

  delay(1000);  // 1초 간격
}
```
</details>


📌 참고 사항    
- 주소 변경: GY-302 센서에서 ADDR 핀을 GND에 연결하면 주소는 0x23, VCC에 연결하면 0x5C입니다. 대부분 GND 또는 미연결(기본 0x23)로 사용됩니다.
- 조도 범위: 약 1~65535 lux까지 측정 가능.
