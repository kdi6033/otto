# Claude 스킬: otto-robot

claude.ai에 한 번 올려 두면, 대화할 때마다 저장소 주소를 붙여 넣지 않아도 Claude가 Otto 로봇의 핀, 함수, 규칙을 알고 코드를 만들어 줍니다.

## 올리는 방법

1. [otto-robot.zip](otto-robot.zip)을 내려받습니다. (파일을 누르고 오른쪽 위 **Download raw file** 버튼)
2. claude.ai에서 **설정(Settings) → 기능(Capabilities) → 스킬(Skills)** 로 갑니다.
3. **스킬 업로드(Upload skill)** 를 누르고 내려받은 zip 파일을 고릅니다. 압축은 풀지 않습니다.
4. 새 대화에서 "Otto 로봇이 앞으로 5걸음 걷고 LED를 초록색으로 켜는 코드를 만들어 줘"처럼 말하면 Claude가 스킬을 사용합니다.

> 메뉴 이름은 claude.ai 화면이 바뀌면 조금 다를 수 있습니다.
> 스킬 내용은 [AGENTS.md](../AGENTS.md)에서 만듭니다. AGENTS.md를 고치면 zip도 다시 만들어 올려야 합니다.
